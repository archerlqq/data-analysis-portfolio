# 客户购物行为数据分析

端到端零售客户行为分析项目：原始 CSV → Python 清洗与特征工程 → MySQL 入库 → SQL 多维分析 → 结果归档 → 分析报告。

分析围绕三条主线：消费金额的驱动因素、客户分层结构、品类与年龄段的营收贡献。

---

## 数据

公开零售数据集 Customer Shopping Trends，3,900 行 × 18 列，含客户属性（年龄、性别、地区）、交易信息（商品、品类、金额）、行为特征（订阅、折扣、历史购买次数、购买频率、配送方式）与评价信息（评分、尺码、颜色、季节）四类字段。

清洗与特征工程的具体口径见分析报告对应章节。

## 分析内容

| 模块    | 查询           | 分析视角                        |
| ----- | ------------ | --------------------------- |
| 数据总览  | 5 条          | 品类与年龄段的营收、销量，订阅占比           |
| 客户价值  | Q1、Q5、Q9、Q12 | 性别营收与客单价、订阅与消费关系、高复购客户的订阅分布 |
| 折扣效应  | Q2、Q6、Q11    | 高消费客户的折扣使用、商品与品类折扣率         |
| 产品表现  | Q3、Q8        | 商品口碑排名、品类内销量前三              |
| 客户结构  | Q7           | 按历史购买次数分层                   |
| 渠道与人群 | Q4、Q10       | 配送方式、年龄段对消费的影响              |

查询覆盖聚合、子查询、CTE 与窗口函数等写法，可直接在 `customer` 表上执行。

## 运行方式

依赖：Python 3、pandas、SQLAlchemy、pymysql、openpyxl；分析阶段需本地 MySQL 8。

1. 可选：运行 `check_customer.py` 查看原始数据的规模、类型与缺失分布
2. 在 MySQL 中创建数据库并配置连接账号，运行 `load_clean_customer.py` 完成清洗并写入 `customer` 表
3. 执行 `customer_sql_queries.sql`，将各查询结果导出为 `results/Q*.csv`
4. 运行 `union_results.py`，合并生成 `SQL_Results.xlsx`

> 入库脚本中的数据库口令需按本机环境配置，公开仓库建议改为读取环境变量。
